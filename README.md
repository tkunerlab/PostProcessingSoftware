PostProcessingSoftware

Java-based software for post-processing single-molecule localization microscopy (SMLM) data, including STORM and PALM.

The software supports drift correction, multicolor image registration, spectral demixing, localization linking, localization precision estimation, and 2D/3D image reconstruction.

Input formats: rapidSTORM and ThunderSTORM localization files (.txt).

Output: Processed localization data, reconstructed images, and exports for Fourier ring correlation (FRC) analysis and ViSP visualization.

Developer: Frank Herrmannsdoerfer (2014)
Additional contributions: M. Klevanski

Programming language: Java
